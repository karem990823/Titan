# HU 15 - Validación de requisitos para inscripción

- **Épica:** Gestión Académica
- **RF Cubierto:** RF-005.1
- **Prioridad:** Alta

## Criterios de Aceptación Cumplidos:
1. **CA-01:** El endpoint GET `/api/cursos/:id/requisitos` entrega las condiciones de inscripción.
2. **CA-02:** El POST `/api/inscripciones` retorna código HTTP 422 con mensaje descriptivo de bloqueo.
3. **CA-03:** En caso de cumplir, retorna HTTP 200 y completa la inscripción.
